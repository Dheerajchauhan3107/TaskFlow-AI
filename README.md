# 🚀 TaskFlow AI

TaskFlow AI is a smart task management web application built using Python and Flask.

## ✨ Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Modern Dashboard
- Responsive UI

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
